Adding new data

This page only monitors — it can't reach out and run a scrape by itself. From your laptop, with .env.local configured (see .env.example), run the command shown above once an event is selected (targets just that event), or run the full pipeline: 

python fall2026catchupscoring.py

Either way, it scrapes locally then pushes into this same hosted database as its last step. Already-final scores and team links here are never overwritten by a rescrape — only filled in if still empty. Refresh this page afterward to see the update.

Scraping GameChanger data

Run these from your laptop, in PerfectGame/, with .env.local configured. Pulls batting/pitching/fielding stats into this same hosted database for the Scouting page.

1. Log in (first time, or after a scrape fails with an auth error)

Opens a real Chrome window — log into GameChanger by hand, then the session is saved for future runs. 

python gamechanger_scrape.py --login

2. First time scraping a team

Replace <team-url> with the team's full GameChanger page URL. <pg-team-key> is the matching PG team's ID (not Team Index) — optional here, you can map it below instead. 

python gamechanger_scrape.py --team-url <team-url> --pg-team-key <pg-team-key>

3. Re-scrape a team already stored

Use the GC team id printed by step 2. Pulls any newly-completed games since the last scrape. 

python gamechanger_scrape.py --gc-team-id <gc-team-id>

GameChanger team links

Links a scraped GameChanger team to an existing Perfect Game team so its stats show up on the Scouting page. Scrape a team first with the steps above, then map it here.
