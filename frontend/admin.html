Adding new data

This page only monitors — it can't reach out and run a scrape by itself. From your laptop, with .env.local configured (see .env.example), run: 

python fall2026catchupscoring.py

That scrapes new games locally, then pushes them into this same hosted database as its last step. Already-final scores and team links already set here are never overwritten by a rescrape — only filled in if still empty. Refresh this page afterward to see the update.
